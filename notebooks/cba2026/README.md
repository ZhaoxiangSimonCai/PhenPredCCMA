# CBA 2026 SHAP analyses

Notebooks in this folder analyze SHAP outputs for the selected +CNV MOSA run `20260505_131645`.

- `01_global_shap_landscape.ipynb`: global omic rankings, global feature rankings, target-level omic composition, and copy-number-specific summary tables.
- `02_target_level_shap_performance.ipynb`: target-level SHAP summaries joined to selected TabPFN performance and RF-baseline deltas.

Both notebooks save publication-oriented figures and derived tables to `reports/cba2026/shap_analysis/20260505_131645/`.
